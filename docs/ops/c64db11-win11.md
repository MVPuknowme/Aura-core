## Windows 11 contract

- Windows platform: `win32`
- Minimum Windows build: `22000`
- Supported architectures: `x64`, `arm64`
- Minimum Node.js major: `24`
- Failure posture: fail closed

Run the target-device preflight from PowerShell on Windows 11:

```powershell
node scripts/skygrid-win11-preflight.mjs
```

The preflight prints a JSON receipt and exits non-zero if the target does not satisfy the contract.

GitHub CI validates the deterministic compatibility policy on both Ubuntu and Windows runners. It does not claim GitHub-hosted Windows Server runners are Windows 11 client devices.
