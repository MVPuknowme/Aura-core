Privacy boundary

Speak uses browser-provided speech APIs only. “Thought Command” is a user-controlled label for explicit text/speech command mode; it does not detect thoughts, hidden signals, nearby people, or devices. Calibration confidence measures only how closely the browser transcript matches a displayed phrase.
