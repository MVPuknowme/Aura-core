Fix Aura runtime architecture.

Correction:
Aura is a Windows 10 local app shell, not an Edge tab and not a raw PowerShell execution console.

Required changes:
1. Local mode must NOT require OpenAI API tokens.
2. If OPENAI_API_KEY is missing, quota-blocked, or invalid, Aura must continue in offline/local mode.
3. Remove or bypass any startup failure caused by OpenAI API quota.
4. Do not execute arbitrary user text as PowerShell.
5. All user input must route through an allowlisted command registry.
6. Unknown commands should return a friendly help message, not execute.
7. Shell commands may only run inside trusted skill functions.
8. Add mode display:
   - Online AI: available/unavailable
   - Local Runtime: active
   - Wallet: read-only
   - Raw shell: disabled
9. Add command:
   Invoke-Aura "vitals"
10. Vitals should show:
   - Runtime loaded
   - Local mode active
   - OpenAI mode: offline if no quota/token
   - Loaded plugins
   - Git status summary
   - Vercel readiness
   - Wallet read-only status
11. Add safety banner on startup:
   "Aura Local Runtime active. Raw shell execution disabled."
12. PowerShell 5.1 compatible.
13. Do not push, deploy, transfer funds, sign wallet transactions, or reveal secrets.

Success test:
. .\aura-runtime.ps1
Invoke-Aura "vitals"
Invoke-Aura "help"
Invoke-Aura "unknown command test"

Expected:
- No OpenAI token required.
- No quota crash.
