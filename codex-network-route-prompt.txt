Build Aura NetworkRoute skill.

Goal:
Aura should inspect approved local/project network routes and recommend the safest working path.

Do NOT scan random public networks.
Do NOT attack, probe, or brute-force external systems.
Only check configured approved endpoints.

Create:
Aura/Skills/NetworkRoute.ps1

Add commands:
Invoke-Aura "network status"
Invoke-Aura "find route"
Invoke-Aura "road less traveled"
Invoke-Aura "switch route"

Config file:
Aura/Config/routes.json

Example routes:
[
  {
    "name": "custom-domain",
    "url": "https://aurcore.skygrid-protocol.net",
    "priority": 1,
    "enabled": true
  },
  {
    "name": "vercel-production",
    "url": "https://aura-core-t2t5.vercel.app",
    "priority": 2,
    "enabled": true
  },
  {
    "name": "skygrid-apex",
    "url": "https://skygrid-protocol.net",
    "priority": 3,
    "enabled": true
  }
]

Behavior:
- Test only enabled routes.
- Check /api/health, /api/highway/status, /api/highway/postman.
- Record HTTP status, latency, and failure reason.
- Pick best route by:
  1. all required endpoints pass
  2. lowest latency
  3. lowest priority number
- Never switch automatically unless permissions.json allows AutoSwitchRoutes=true.
- If AutoSwitchRoutes=false, recommend the route only.
- Save selected route to Aura/Config/active-route.json.
- Log all checks to Aura/Logs/network-route.log.
- PowerShell 5.1 compatible.
- No destructive actions.
- No secrets.

Success test:
. .\aura-runtime.ps1
Invoke-Aura "road less traveled"
