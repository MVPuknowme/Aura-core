# SKYGRID Training Receipts

Generated receipts from `scripts/skygrid-training-drill.mjs` are written here.

Receipt files are proof artifacts for simulated training only. They should include:

- run id
- product name
- base URL
- scenario pack path
- scenario results
- request and response summaries
- assertion status
- safety guard status
- timestamp

Do not place secrets, private incident data, wallet keys, customer data, or live emergency records in this folder.
