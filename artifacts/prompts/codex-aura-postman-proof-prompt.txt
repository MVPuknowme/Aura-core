Build Aura PostmanProof skill.

Goal:
Aura should run local Newman/Postman proof tests against the currently selected active route and save validation artifacts.

Aura rules:
- Local mode only.
- No OpenAI API required.
- No raw shell execution from user text.
- User phrases route through allowlisted skills.
- Do not push.
- Do not deploy.
- Do not change branches.
- Do not expose secrets.

Create:
Aura/Skills/PostmanProof.ps1

Add friendly commands:
- run proof
- postman proof
- test api routes
- validate emergency on-ramp

Function:
Invoke-AuraPostmanProof

Behavior:
1. Read active route from:
   Aura/State/active-route.json

2. If no active route exists, recommend:
   Invoke-AuraRuntime "road less traveled"

3. Detect Newman:
   newman --version

4. Detect collection:
   postman/skygrid-aura-desktop.generated.collection.json

5. Run Newman against active route:
   newman run postman/skygrid-aura-desktop.generated.collection.json `
     --env-var "base_url=<active route url>" `
     --reporters cli,json `
     --reporter-json-export artifacts/validation/aura-postman-proof.json

6. Save a markdown summary:
   artifacts/validation/aura-postman-proof.md

7. Output:
   AURA POSTMAN PROOF
   ------------------
   Active Route:
   Collection:
   Newman:
   Result:
   Recommendation:

8. If proof passes:
   Recommendation:
   Checkpoint validation artifacts when ready.

9. If proof fails:
   Recommendation:
   Review failing route/collection before checkpoint.

Runtime integration:
Wire these phrases into aura-runtime.ps1:
- run proof

- validate emergency on-ramp

All should call:
Invoke-AuraPostmanProof

Update Aura/Config/commands.json with matching entries.
