Build Aura PCAnalytics skill using AWS IoT-style local JSON telemetry.

Goal:
Aura should inspect internal Windows PC health and write local analytics JSON files shaped like AWS IoT/device telemetry.

Important:
This is local/read-only analytics first.
Do not publish to AWS IoT yet.
Do not require AWS credentials.
Do not require OpenAI API.
Do not expose secrets.
Do not collect private file contents.
Do not print environment secrets.
Do not send telemetry over the network.

Create:
Aura/Skills/PcAnalytics.ps1

Friendly commands:
- pc analytics
- pc vitals
- device telemetry
- internal analytics
- aws iot json
- iot status

Functions:
- Invoke-AuraPcAnalytics
- Invoke-AuraPcVitals
- Export-AuraAwsIotJson
- Show-AuraIotStatus

Folders:
artifacts/iot/
artifacts/iot/pc-analytics/
artifacts/iot/proofs/

Behavior:

Invoke-AuraPcAnalytics:
1. Collect read-only system analytics:
   - computer name
   - Windows version
   - uptime
   - CPU load
   - memory total/free/used percent
   - disk total/free/used percent
   - network adapters that are up
   - active Aura route from Aura/State/active-route.json if present
   - count proof files under artifacts/

2. Save JSON to:
   artifacts/iot/pc-analytics/<timestamp>-pc-analytics.json

3. Save Markdown summary to:
   artifacts/iot/proofs/<timestamp>-pc-analytics-proof.md

4. Output:
   AURA PC ANALYTICS
   -----------------
   Device:
   OS:
   Uptime:
   CPU:
   Memory:
   Disk:
   Network:
   Active Route:
   JSON:
   Proof:
   Recommendation:

Invoke-AuraPcVitals:
- Short console summary only.
- No file write unless user runs pc analytics.

Export-AuraAwsIotJson:
- Create/latest AWS IoT-style JSON payload locally.
- Do not publish.
- Print where file was saved.

Show-AuraIotStatus:
- Count analytics JSONs.
- Show newest 5.
- Show whether AWS publish is disabled.
- Show recommendation.

Runtime integration:
Wire these phrases into aura-runtime.ps1:
- pc analytics
- pc vitals
- device telemetry
- internal analytics
- aws iot json
- iot status

Update Aura/Config/commands.json with matching entries.

Safety:
- No AWS publish.
- No network upload.
- No secrets.
- No raw command execution from user input.
- No file content scanning.
- No wallet signing.
- No deploy.
- No push.

PowerShell 5.1 compatible.
